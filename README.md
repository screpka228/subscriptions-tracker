# Трекер подписок

Простое веб-приложение, чтобы видеть все свои подписки в одном месте: сколько уходит в месяц и в год и когда будет следующее списание.

Работает в браузере, без сервера и без сторонних библиотек. Устанавливается на телефон как приложение (PWA).

## Возможности

- Список подписок: название, сумма, валюта (RUB, USD, EUR), периодичность (раз в месяц или в год), дата следующего списания, категория, откуда списывается, примечание.
- Блок «Скоро списания» вверху: подписки, которые спишутся в ближайшие 7 дней.
- Даты пересчитываются сами: если дата уже прошла, она переносится на ближайший будущий период.
- Итоги в рублях в месяц и в год. Для USD и EUR нужно указать курс в настройках.
- Экспорт всех подписок в файл `subscriptions.json` и импорт из него.
- Тёмная тема. По умолчанию следует системной настройке.
- Уведомления через браузер, если он их поддерживает.

## Приватность

- Данные хранятся только в localStorage вашего браузера. На сервер ничего не отправляется.
- В поле «Откуда списывается» пишите только описание вроде «карта Сбера» или «кошелёк Apple ID». Номера карт, CVV и другие платёжные данные не нужны.
- Если в это поле ввести что-то похожее на номер карты, приложение не сохранит подписку и покажет предупреждение.

## Как пользоваться

Откройте сайт в браузере. На телефоне:

- **iPhone:** Safari → «Поделиться» → «На экран «Домой»».
- **Android:** Chrome → меню → «Установить приложение».

## Структура

```
index.html     приложение: интерфейс, стили и логика в одном файле
manifest.json  описание PWA (название, иконки, цвета)
sw.js          service worker: открытие без сети
icon.svg       иконка
icon-*.png     иконки для iPhone и Android
```

Логика работы с данными сгруппирована в `DataStore` и отдельных функциях (`migrate`, `refreshDates`, `calculateTotals`). Если позже понадобится синхронизация через Supabase или Firebase, менять нужно только слой хранения, интерфейс останется прежним.

Файл экспорта содержит поле `version`, по нему при импорте старые файлы обновляются до текущей схемы.

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: Deploy from a branch.
3. Branch: `main`, папка `/ (root)`.
4. Сохранить. Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.
