# 📅 Трекер подписок

Веб-приложение, чтобы видеть все подписки в одном месте: сколько уходит в месяц и в год и когда следующее списание.

**[Открыть приложение →](https://screpka228.github.io/subscriptions-tracker/)**

Без сервера и без сторонних библиотек. Работает в браузере и ставится на телефон как приложение (PWA).

## ✨ Возможности

- **Подписки.** Название, сумма, валюта (RUB, USD, EUR), периодичность (в месяц или в год), дата следующего списания, категория, откуда списывается, примечание.
- **Скоро списания.** Блок вверху показывает подписки, которые спишутся в ближайшие 7 дней.
- **Автопересчёт дат.** Если дата уже прошла, она переносится на ближайший будущий период.
- **Итоги в рублях.** Сумма в месяц и в год. Для USD и EUR нужен курс, который задаётся в настройках.
- **Экспорт и импорт.** Все подписки сохраняются в `subscriptions.json` и загружаются обратно. При импорте файл проверяется, а некорректный файл не меняет данные.
- **Тёмная тема.** Системная, светлая или тёмная, запоминается в браузере.
- **Уведомления.** Через Notification API, если браузер их поддерживает.

## 🔒 Приватность

- Данные хранятся только в `localStorage` вашего браузера. На сервер ничего не отправляется.
- В поле «Откуда списывается» пишите описание, например «карта Сбера» или «кошелёк Apple ID». Номера карт, CVV и другие платёжные данные не нужны.
- Если в этом поле введён номер карты, подписка не сохранится, а приложение покажет предупреждение.

## 📱 Установка на телефон

- **iPhone:** откройте сайт в Safari → «Поделиться» → «На экран «Домой»».
- **Android:** откройте сайт в Chrome → меню → «Установить приложение».

## 🛠 Запуск локально

Это статический сайт, сборка не нужна. Достаточно открыть `index.html` через любой локальный сервер, например:

```bash
npx serve .
```

Service worker не работает при открытии файла напрямую (`file://`), поэтому используйте сервер.

## 🗂 Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Приложение: интерфейс, стили и логика в одном файле |
| `manifest.json` | Описание PWA: название, иконки, цвета |
| `sw.js` | Service worker: открытие приложения без сети |
| `icon.svg`, `icon-*.png` | Иконки для браузера, iPhone и Android |

Работа с данными сосредоточена в `DataStore` и отдельных функциях (`migrate`, `refreshDates`, `calculateTotals`). Синхронизацию через Supabase или Firebase можно подключить, заменив слой хранения, не меняя интерфейс.

## 📦 Формат файла экспорта

```json
{
  "version": 1,
  "exportedAt": "2026-10-21T12:00:00.000Z",
  "subscriptions": [
    {
      "id": "m2k4x9a1b2c3d",
      "name": "Netflix",
      "amount": 1000,
      "currency": "RUB",
      "period": "monthly",
      "nextDate": "2026-11-05",
      "category": "Видео",
      "source": "карта Сбера",
      "note": ""
    }
  ]
}
```

Поле `version` нужно для обновления старых файлов при импорте.
